# Caturaya Living

Website MVP untuk Caturaya Living, layanan interior, aluminium, kitchen set, plafon, kanopi, partisi, dan home finishing di Sidareja, Cilacap, dan sekitarnya.

## Stack

- Next.js
- TypeScript
- CSS Modules
- Vercel-ready

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy

Project ini disiapkan untuk deploy gratis di Vercel.
